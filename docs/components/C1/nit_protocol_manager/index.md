# NIT Protocol Manager

The NIT Protocol Manager (C1) is designed to ensure that clinical treatment plans adhere to the NIT (Nivel de Intensidad Terapéutica) protocol. It acts as an integration and decision-support component that analyzes proposed treatment actions against the patient's assigned therapeutic intensity level to determine if specific interventions are permissible according to established clinical guidelines.

By subscribing to treatment proposals, the component validates each action within the treatment plan and provides immediate feedback on whether the action is allowed, denied, or unknown based on the NIT protocol constraints.
