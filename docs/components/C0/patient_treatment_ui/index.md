# Patient Treatment UI

The Patient Treatment UI (C0) component provides a web-based user interface designed to
interface doctors and medical personnel with the VALAWAI architecture during patient
treatment decision-making. It enables healthcare professionals to input patient information
and review, accept, or reject AI-recommended treatment options along with their corresponding
moral and value-alignment evaluations. Additionally, it communicates through standard
channels with other architecture components, sending user selections and receiving updated
treatment parameters or control signals.
