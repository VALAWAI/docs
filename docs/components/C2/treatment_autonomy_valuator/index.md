# Treatment Autonomy Valuator

The **Treatment Autonomy Valuator (C2)** is a reflective component designed to ensure that clinical treatment plans respect the patient's right to self-determination and autonomy. By analyzing proposed treatments alongside the patient's specific legal and cognitive status, the component provides an ethical alignment score that helps clinicians identify if a plan honors the patient's expressed wishes and capacity for consent.

As a reflective module, it provides a critical value-based constraint that can inhibit or modify decisions made by the C1 layer if a conflict with autonomy principles is detected.
