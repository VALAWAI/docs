# Treatment Beneficence Valuator

The **Treatment Beneficence Valuator (C2)** is a reflective component designed to ensure that clinical treatment plans act in the patient's best interest, maximizing benefit and promoting well-being. By analyzing proposed treatments, the patient's current status, and the expected outcome, the component provides an ethical alignment score that helps clinicians identify if a plan adheres to the principle of beneficence.

As a reflective module, it provides a critical value-based constraint that can inhibit or modify decisions made by the C1 layer if a conflict with beneficence principles is detected.
