# Treatment Justice Valuator

The **Treatment Justice Valuator (C2)** is a reflective component designed to ensure that clinical treatment plans are distributed fairly and equitably. By analyzing the proposed treatment and the patient's socio-clinical profile, the component provides an ethical alignment score that helps clinicians identify if a plan adheres to the principle of justice—ensuring that similar cases are treated similarly and that resources are allocated without bias.

As a reflective module, it provides a critical value-based constraint that can inhibit or modify decisions made by the C1 layer if a conflict with justice principles is detected.
